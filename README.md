# Ayrık Matematik - Mantık ve Önermeler Ödevi

Bu depo, Kahramanmaraş İstiklal Üniversitesi Yazılım Mühendisliği bölümü Ayrık Matematik dersi 1. hafta görevleri kapsamında hazırlanmış mantık ödevini içermektedir.

## 📌 İçerik
- Önermeler ve Bileşik Önermeler kavramları
- Doğruluk Tabloları (Ve, Veya, İse, Ancak ve Ancak)
- Mantıksal Eşdeğerlilik, Totoloji ve Çelişki ispatları
- Çözümlü problemler ve değerlendirme alıştırmaları
